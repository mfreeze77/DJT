# Visual Timeline Financial Reconciliation
## Yearly JSON review for Russian-linked money, project capital, and cultivation value
### Source branch: `Visual_Timeline`

## Scope

The yearly files reviewed are located at:

```text
trump-russia-timeline/data/processed/by-year/
```

The branch contains annual JSON datasets spanning **1971 through 2015**. Each file can contain:

- events;
- people and organizations;
- relationships;
- money-flow objects;
- normalized transactions;
- Russian-connection flags;
- intelligence activities;
- evidence-strength fields;
- source links;
- and Panama Papers metadata.

This is a valuable investigative structure. It is not a substitute for the underlying source.

The promoted financial findings are recorded in:

- [`Tmanch_Russian_Linked_Financial_Flows.csv`](Tmanch_Russian_Linked_Financial_Flows.csv)
- [`Tmanch_Russian_Linked_Financial_Methodology.md`](Tmanch_Russian_Linked_Financial_Methodology.md)

# 1. Chronological reconciliation

## 1971–1981 — access and platform formation, not identified Russian cash

The early files document family, immigration, business, and property foundations. They do not presently establish Russian payments to Trump.

## 1982 — Atlantic City platform

The 1982 file records the approximately **$210 million** Holiday Inn/Harrah’s casino development partnership.

**Classification:** U.S. corporate project capital.

**Importance to the Russian-money inquiry:** the casino and hospitality platform later created cash, high-roller, aviation, brokerage, and regulatory interfaces.

**Correction:** do not describe the $210 million as Russian money.

## 1983 — Trump Tower platform

The 1983 file records approximately **$200 million** of Trump Tower development value and Equitable Life’s major role.

**Classification:** U.S. institutional project capital.

**Importance:** the resulting condominium building offered high-value units, privacy, international marketing, and an early mechanism for bulk or opaque foreign purchases.

## 1984 — first explicit Russian-linked direct cash flow

The 1984 file records David Bogatin’s purchase of five Trump Tower units for approximately **$6 million cash**.

**Promoted:** yes.

**Qualification:** gross project sale value, not Trump personal net income.

**External support required:** forfeiture records, deeds, closing records, and contemporaneous criminal-case reporting.

## 1985 — casino expansion and Weichselbaum context

The 1985 file principally documents domestic casino growth, debt, and business exposure. Russian cash is not independently established for that year.

## 1986 — Soviet diplomatic approach

# 2. Schema and evidence-quality findings

## 2.1 `moneyFlow.amount` is not consistently the same economic concept

Across years, `amount` may mean:

- purchase price;
- proposed project value;
- debt restructured;
- loan principal;
- estimated equity value;
- fine;
- gross receipts;
- alleged or reported benefit;
- or zero-dollar relationship formation.

A future schema should add:

```json
{
  "amountRole": "gross-sale|net-income|loan|project-value|proposal|fine|equity-estimate|expense|non-cash",
  "amountRecipient": "person|controlled-entity|part-owned-project|partner|unknown",
  "amountConfidence": "primary|official|documentary|alleged|estimated|unsupported",
  "isRealized": true,
  "isNet": false,
  "overlapGroup": "string-or-null"
}
```

## 2.2 `isRussianConnected` requires a typed connection

A boolean cannot distinguish:

- Russian nationality;
- Russian state or state bank;
- oligarch or politically exposed person;
- organized crime;
- former-Soviet origin;
- Russian customer demand;
- disputed source of funds;
- or merely a Russian-facing project.

Use an enumerated array rather than one flag.

## 2.3 `evidenceStrength` must be supported by source presence

Some entries are labeled `confirmed` or `strong` while their source arrays are empty or point only to another repository file.

Recommended rule:

- `confirmed` requires a primary, official, judicial, regulatory, contract, property, tax-derived, or independently corroborated documentary source;
- an empty source array caps the entry at `unverified-lead`;
- a repository markdown file is a research pointer, not independent substantiation.

## 2.4 Duplicate detection is required before summation

Each transaction should carry:

- canonical transaction ID;
- property and unit ID;
- source universe;
- overlap group;
- parent portfolio ID;
- whether the row is a subtotal or component.

## 2.5 Gross, net, and ownership allocation must be separated

A $6 million unit purchase, $95 million property sale, $50 million project investment, and $25 million estimated equity value cannot be added as though they are equivalent Trump income.

# 3. Recommended Visual Timeline branch corrections

1. Add `amountRole`, `amountRecipient`, `isRealized`, `isNet`, and `overlapGroup` fields.
2. Replace the Boolean Russian flag with typed connection categories.
3. Remove unsupported dollar estimates or label them explicitly as unresolved.
4. Add source requirements for `confirmed` and `strong` evidence.
5. Deduplicate the 2013 pageant and 2010–2011 property events.
6. Separate:
   - Trump personal income;
   - controlled-entity receipts;
   - project transaction volume;
   - indirect capital;
   - proposed value;
   - non-cash access.
7. Link every yearly event to the current chapter claim ledger and primary-source inventory.
8. Extend the yearly dataset beyond 2015 using Chapters 5–7.
9. Add a derived financial view generated from the corrected canonical transactions rather than manually entered totals.
10. Preserve rejected amounts and corrections in an audit log rather than silently deleting them.

# 4. Conclusion

The yearly JSON files materially improve the research because they reveal the financial chronology alongside intelligence, criminal, property, and political events.

They also demonstrate why the conclusion previously understated the financial dimension.

The strongest supported narrative is:

> **The 1982–1983 transactions built the leveraged casino and luxury-property platform. The first explicit Russian criminal-linked purchase in the structured dataset occurred in 1984. Russian and post-Soviet money then recurred through property purchases, oligarch transactions, pageant underwriting, project partners, indirect financing leads, and ordinary customer demand. A conservative source-controlled reconstruction identifies at least $103.3 million in direct receipts or payouts and $211.4 million in non-overlapping gross transaction or project value, while excluding unsupported, overlapping, disputed, prospective, and unquantified flows.**

That finding is financially significant. It is not, by itself, proof that Russia directed every transaction or purchased every later policy.
