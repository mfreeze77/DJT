## Ongoing linkage rule

For each proposed addition, record existing claim IDs and source-family/event IDs, then label the change as new event, new evidence about an existing event, source verification, correction, analytical extension, or duplicate. Preserve the distinction between an observed statement, an existing vulnerability inference, and a causal explanation that is being tested.
